README 
--- CREATEBD.txt
O arquivo CREATEBD consiste na criação das tabelas do nosso banco de dados, além de no seu final, estar disponibilizado certos códigos de como foram gerados e aleatorizados os dados.

--- INSERT_BD.txt 
Consiste na inserção dos dados por totalidade no Banco de Dados, todo esse arquivo foi gerado sob a automatização por python mediante à um arquivo anterior que utilizei de softwares livres de geração de dados e assistentes de IA como Gemini, ChatGPT e Claude. 
Os maiores detalhes de inserção foram determinados nos slides e na apresentação. 

--- SP_TRIGG_CONS.txt
Este arquivo expressas todas as consultas frequentes, visões, stored procedures e triggers utilizados no nosso BD. 

--- AnáliseRPOSTGREE.rmd e .pdf 
Consiste na análise dos dados utilizando R.
